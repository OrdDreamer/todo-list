# ✅ Todo List - Додаток для управління завданнями

## 📘 Опис проекту

**Todo List** — це простий та ефективний веб-додаток для управління щоденними завданнями. Система дозволяє створювати завдання, організовувати їх за допомогою тегів, встановлювати дедлайни та відстежувати їх статус виконання.

Основні можливості:
- створювати та керувати завданнями
- організовувати завдання за допомогою тегів
- встановлювати опціональні дедлайни
- позначати завдання як виконані або невиконані
- переглядати завдання, відсортовані за статусом та датою створення

---

## ✨ Функціонал

### Управління завданнями
- **CRUD операції**: створення, перегляд, редагування та видалення завдань
- **Зміст завдання**: детальний опис того, що потрібно зробити
- **Дедлайни**: опціональна дата та час завершення завдання
- **Статус виконання**: позначати завдання як виконані або невиконані одним кліком
- **Сортування завдань**: завдання автоматично сортуються за статусом (спочатку невиконані) та датою створення (спочатку новіші)
- **Теги**: призначати кілька тегів завданням для кращої організації

### Управління тегами
- **CRUD операції**: створення, перегляд, редагування та видалення тегів
- **Призначення тегів**: призначати кілька тегів завданням
- **Список тегів**: перегляд усіх доступних тегів у форматі таблиці

## 📋 Встановлення

### Вимоги

- Python 3.8 або вище
- pip (менеджер пакетів Python)

### Крок 1: Клонувати репозиторій

```bash
git clone <repository-url>
cd todo-list
```

### Крок 2: Створити віртуальне середовище

```bash
python -m venv venv
```

Активувати віртуальне середовище:

**Linux/Mac:**
```bash
source venv/bin/activate
```

**Windows:**
```bash
venv\Scripts\activate
```

### Крок 3: Встановити залежності

```bash
pip install -r requirements.txt
```

### Крок 4: Застосувати міграції

```bash
python manage.py migrate
```

### Крок 5: Створити суперкористувача (опціонально)

Для доступу до панелі адміністратора Django:

```bash
python manage.py createsuperuser
```

## 🚀 Запуск проекту

Після виконання всіх кроків встановлення запустіть сервер розробки:

```bash
python manage.py runserver
```

Додаток буде доступний за адресою: **http://127.0.0.1:8000/**

## 🗄️ Моделі даних

### Tag (Тег)
- `name` — назва тега (унікальна)
- Зв'язок: Tag ↔ Task (ManyToMany)

### Task (Завдання)
- `content` — опис завдання (TextField)
- `created_at` — дата та час створення завдання (автоматично)
- `deadline` — опціональна дата та час завершення (nullable)
- `is_done` — статус виконання (Boolean, за замовчуванням: False)
- `tags` — пов'язані теги (ManyToMany до Tag)
- Зв'язки:
  - Task ↔ Tag (ManyToMany)

## 🔗 Основні URL маршрути

- `/` — головна сторінка (список завдань)
- `/task/create/` — створити нове завдання
- `/task/<id>/update/` — редагувати завдання
- `/task/<id>/delete/` — видалити завдання
- `/task/<id>/toggle/` — змінити статус виконання завдання
- `/tags/` — список тегів
- `/tag/create/` — створити новий тег
- `/tag/<id>/update/` — редагувати тег
- `/tag/<id>/delete/` — видалити тег
- `/admin/` — панель адміністратора Django

## 📝 Додаткові примітки

- Завдання автоматично сортуються за статусом виконання (спочатку невиконані) та датою створення (спочатку новіші)
- Для списку завдань використовується пагінація (20 елементів на сторінку)
- Форми стилізовані за допомогою Bootstrap 5 через Django Crispy Forms
- Бічна панель присутня на всіх сторінках для зручної навігації
- Статус виконання завдання можна змінити одним кліком
